# Parcel Damage CV · результаты

## Данные и протокол

[Corrugated Cardboard Boxes Dataset](https://github.com/chanllon/corrugated-cardboard-boxes-dataset) содержит фотографии физических коробок. Часть повреждений авторы нанесли специально. Основная выборка включает 156 кадров с разметкой, из них 56 положительных. В разработку вошли 132 кадра из 44 групп префиксов, в тест — 24 кадра из восьми новых групп. В тесте 9 положительных кадров, поэтому AP постоянного скоринга равна 0,375. Префиксы используются для группировки при разбиении. Их соответствие отдельным физическим коробкам авторы явно не описали. Проведённые проверки дублей, выборка и прочие ограничения описаны в [расширенном эксперименте](EXPANDED_RESULTS.md).

Метки относятся к видимым повреждениям упаковки на конкретном фото. Исходные фотографии доступны у авторов. В репозитории хранятся пути, контрольные суммы, разметка для экспериментов и производные метрики.

## Что сравнили

| Подход | Средняя AP на фолдах разработки | AP на итоговом тесте |
|---|---:|---:|
| Логистическая регрессия, признаки цвета и границ, весь кадр | 0,503 | 0,433 |
| HOG + SVM, весь кадр | 0,480 | 0,493 |
| HOG + SVM, ручная рамка | 0,361 | 0,632 |
| HOG + SVM, рамка по цвету | 0,391 | 0,542 |
| HOG + SVM, обучаемая рамка | 0,422 | 0,498 |
| HOG + SVM со сдвигами рамки при обучении, обучаемая рамка | 0,359 | 0,683 |
| CNN с нуля, ручная рамка | 0,411 | 0,355 |
| MobileNetV3, весь кадр | 0,434 | 0,531 |
| MobileNetV3, ручная рамка | 0,386 | 0,838 |
| MobileNetV3, рамка по цвету | 0,377 | 0,536 |
| MobileNetV3, обучаемая рамка | 0,432 | 0,797 |

MobileNetV3 Small использует фиксированные веса ImageNet. Для каждого фолда на эмбеддингах обучена отдельная логистическая регрессия. В сравнении способов обрезки классификатор обучается на ручных рамках разработки, а рамки тестовых снимков предсказываются автоматически. Истинные рамки теста нужны для расчёта IoU и сравнения с ручной обрезкой. Все сравнения используют одинаковое разбиение.

Обучаемая рамка строится из вероятностей принадлежности пикселей коробке. Для обучения Extra Trees использованы цвет, локально сглаженный цвет и координаты. Порог и морфологические операции фиксированы. На тесте средний IoU составил **0,722**. Все 24 рамки имели IoU не ниже 0,5. Эвристика по цвету дала IoU **0,649** и прошла этот порог в 17 из 24 случаев. Скрипт использует полный кадр, если алгоритм не нашёл подходящую компоненту.

**Наиболее перспективная комбинация из проверенных на итоговом тесте** — обучаемая рамка и MobileNetV3. Разброс результатов по группам велик. Логистическая регрессия по всему кадру лидировала на фолдах разработки в сравнении всех признаков. Поэтому AP 0,797 характеризует этот тест, а для выбора модели на реальных обращениях нужна новая выборка из нескольких мест съёмки. На первом пилоте из 42 фото MobileNetV3 по всему кадру дала AP 0,929. Результат на более широкой выборке показывает, почему пилотной метрики недостаточно.

## Перенос на фотографии из пункта выдачи

Для дополнительной проверки использована папка `post_station` того же публичного источника. Из списка числовых имён с размером файла до 1 MiB последовательно взяты 18 равномерно распределённых кадров. Шесть неоднозначных кадров исключены после визуального просмотра (17, 30, 47, 51, 59, 67). У оставшихся 12 фото вручную отмечены пять видимых повреждений упаковки. Метки поставлены по фотографиям до расчёта предсказаний. Разделение осмотров по независимым физическим посылкам для этого набора не подтверждено, поэтому результаты диагностические.

| Замороженный классификатор и вход | AP | ROC-AUC |
|---|---:|---:|
| HOG + SVM, весь кадр | 0,527 | 0,429 |
| HOG + SVM, рамка по цвету | 0,376 | 0,343 |
| HOG + SVM, обучаемая рамка | 0,337 | 0,229 |
| MobileNetV3, обучаемая рамка | 0,492 | 0,514 |

Все головы в этой проверке обучены на ручных обрезках основного датасета. Модели, пороги и способы обрезки оставлены в исходном виде. AP постоянного скоринга равна 5/12 ≈ 0,417. Результат MobileNetV3 здесь ниже, чем на основном тесте. Среди кадров есть серые и зелёные коробки и крупные снимки без широкого фона. Эти факторы стоит включить в отдельную проверку устойчивости детектора и классификатора.

## Повторение экспериментов

```bash
python -m pip install -r requirements-expanded.txt -r requirements-pretrained.txt
python parcel_cv.py demo
python real_benchmark.py data/real --download --pretrained --synthetic-baseline run/demo/model.joblib --out run/real-pretrained
python real_advanced.py data/real --download --pretrained --out run/expanded-pretrained
python box_pipeline.py evaluate data/real --pretrained
python station_check.py run/box-pipeline/model.joblib data/stations --download
```

Запуск для отдельного фото после обучения:

```bash
python box_pipeline.py predict run/box-pipeline/model.joblib path/to/parcel.jpg --method mobilenet
```

Команда возвращает рамку в относительных координатах исходного изображения и оценку для ранжирования. Оценка не калибрована как вероятность. Веса MobileNetV3 получает TorchVision. Файлы обученных моделей генерируются локально.

История сравнения и сохранённые результаты находятся в [example-results](example-results/). Многокадровую логику проверили на синтетических обращениях. [Протокол и шаблон](REAL_DATA.md) готовы для проверки по сериям реальных снимков одной физической коробки. Подтверждённых серий для такого теста пока нет.
