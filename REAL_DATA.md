# Эксперимент на реальных фотографиях

Задача этого эксперимента — ранжировать отдельные фотографии по наличию размеченного повреждения упаковки. Прототип обработки нескольких ракурсов по-прежнему можно проверить на синтетическом наборе из основного README.

## Источник и выборка

Фотографии взяты из [Corrugated Cardboard Boxes Dataset](https://github.com/chanllon/corrugated-cardboard-boxes-dataset). Авторы снимали физические курьерские коробки на смартфон и намеренно наносили часть дефектов. В `real_index.csv` указаны исходные пути, контрольные суммы и метки. В архив входят ссылки и результаты эксперимента. Исходные файлы загружаются по команде из публичного репозитория.

Для пилота взяты 14 префиксов из имён файлов. В каждом просмотрена разметка пяти наиболее компактных снимков. Выбрано по три фото на префикс, по возможности одно с рамкой `damage` и одно без неё. Всего 42 фотографии, из них 11 с размеченным повреждением. Отсутствие рамки означает отсутствие отметки о видимом повреждении на данном кадре. Состояние коробки со всех сторон неизвестно. Состав выборки задан для эксперимента, поэтому доля повреждений не оценивает их реальную частоту.

Префикс использован как группа при разбиении. Авторы не документируют соответствие префиксов физическим коробкам. Все 42 снимка прошли проверку SHA-256, точных дубликатов среди них нет. Минимальное расстояние dHash между снимками из разных фолдов — 14 из 64 бит. Эта проверка улавливает близкие копии, а разные виды одной коробки могут пройти её.

## Результаты

Каждый из четырёх фолдов содержит отложенные группы префиксов и 2–3 изображения с дефектами. Таблица показывает AP и ROC-AUC по всем отложенным предсказаниям. У фиксированной модели первой версии обучение проводилось на синтетике, оценка — на всех 42 реальных кадрах.

| Модель | AP | ROC-AUC |
|---|---:|---:|
| Модель из первой версии, без обучения на реальных фото | 0,252 | 0,472 |
| Логистическая регрессия на реальных фото | 0,270 | 0,469 |
| Extra Trees на реальных фото | 0,345 | 0,604 |

Доля положительных кадров, ориентир AP для постоянного скоринга, — 0,262. Результат Extra Trees обнадёживает для продолжения, но выборка мала. Это пилотная оценка по кадрам. Для оценки сортировки обращений нужны серии с подтверждённым ID коробки. Сводка по фолдам и оценки отдельных изображений лежат в `example-results/real/`.

## Повторить прогон

```bash
python -m pip install -r requirements.txt
python parcel_cv.py demo
python real_benchmark.py data/real --download --synthetic-baseline run/demo/model.joblib
```

Если файлы уже скачаны, передай папку с JPG и опусти `--download`. Скрипт проверит их хеши. Путь исходного коммита закреплён в коде.

Для сравнения с предобученными эмбеддингами MobileNetV3 Small предусмотрен отдельный запуск на тех же фолдах:

```bash
python -m pip install -r requirements-pretrained.txt
python real_benchmark.py data/real --pretrained --out run/real-pretrained
```

При первом запуске TorchVision загружает веса ImageNet. Последующий прогон с доступными весами описан в [итоговом отчёте](FINAL_RESULTS.md).

## Независимая выборка для нескольких ракурсов

`real_multiview_template.csv` подготовлен для 30 физических курьерских коробок. Для каждой нужны два снимка основных ракурсов, а при необходимости можно добавить строки для дополнительных снимков тех же сторон. Состояние коробки подтверждается осмотром или отдельным комплектом контрольных фото. Плохие снимки помечаются как непригодные, даже когда известно, что сама коробка повреждена.

Для независимого теста зафиксируй модель и пороги до просмотра меток этих 30 коробок. Затем сравни первый снимок со всем комплектом по пропущенным повреждениям, ложным сигналам и доле обращений на ручную проверку. Если после пилота модель менялась по ошибкам этой выборки, следующую независимую проверку проведи на других коробках.

После заполнения шаблона сохрани его рядом с папкой `images/` и запусти проверку с фиксированным файлом модели:

```bash
python multiview_test.py run/demo/model.joblib data/claims/manifest.csv
```

Команда использует первую строку каждого обращения для сценария одного фото. Перед запуском зафиксируй порядок кадров, например порядок получения от клиента. Файл модели должен быть получен на других коробках.
